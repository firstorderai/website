How to setup 2FA for Amazon Web Services account?

To setup 2FA for your Amazon Web Services (AWS) account with our Authenticator App, you need to follow the next steps:

  1. Log in to the AWS console as an administrator.

  2. Go to Security, Identity & Compliance.

  3. Select IAM (Identity and Access Management).

  4. Select Identity Providers.

  5. Select Create Provider.

  6. Go to Policies > App Authentication Policy.

  7. Select Edit for the application you want to configure.

  8. Enable Enable 2-Factor Authentication (MFA).

  9. Select Save.

  10. Choose the type of MFA device you want to use.

  11. Start your authentication program and scan the QR code.

  12. In this step, a QR code containing the secret key is displayed. Next, you need to use our Authenticator App to scan this QR code. Please keep this popup open to complete the setup.

  13. Open our Authenticator App, click the + button at the bottom right of the screen, then hold your device near the computer screen to scan the QR code.

  14. After successfully scanning, a 6-digit code will be shown at the bottom of the screen. Please note that this code refreshes every 30 seconds.

  15. Return to the AWS webpage, key in the 6-digit code displayed in step 14, and then click Confirm.

  16. Remember to click "Save" in the Authenticator App to save your account, or you may lose access to your account!
